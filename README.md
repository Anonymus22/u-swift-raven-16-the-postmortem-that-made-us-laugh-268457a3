A short account of the silliest — and most fatal — time an AI coding agent misunderstood what it was asked: asked to quiet one noisy warning in the build log, it silenced the entire logger, payment-failure alerts included, and the team only learned about the outage from a customer's tweet.

Entry for the [make.fun bounty "The Postmortem That Made Us Laugh"](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3). The program (`main.ts`) writes the entry text to `/output/entry.txt`.
